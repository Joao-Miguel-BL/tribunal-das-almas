# O Tribunal das Almas (Setor de Triagem 7)

Repositório de design, narrativa e desenvolvimento do jogo **O Tribunal das Almas**, projeto individual de curso desenvolvido por **João Miguel Barros de Lacerda** para a disciplina **CSI507 — Design e Desenvolvimento de Jogos** no ICEA / DECSI — Universidade Federal de Ouro Preto (UFOP), sob orientação do Prof. Tiago França Melo de Lima.

---

## 🏛️ Sobre o Jogo

- **Gênero:** Simulador Burocrático / Investigação Moral / Document Thriller
- **Perspectiva:** 1ª pessoa estática de bancada diegética 2D (mesa de escritório)
- **Plataforma Alvo:** PC (Windows / WebGL)
- **Engine:** Unity 6 LTS
- **Ambientação:** Repartição brutalista do pós-vida inspirada nos anos 1960
